# Student Management System

## 📌 Project Description
Student Management System is a Java-based application used to manage student records such as student details, marks.

## 🚀 Features
- Add new student
- View student details
- Update student information
- Delete student record

## 🛠 Technologies Used
- Java
- JDBC
- MySQL
- OOP Concepts

## 📂 Project Structure
StudentManagementSystem
│
├── Main.java
├── Student.java
├── DatabaseConnection.java
└── StudentDAO.java

## ▶️ How to Run
1. Install Java (JDK 8 or above)
2. Install MySQL
3. Configure database connection in the project
4. Compile and run the Main.java file
